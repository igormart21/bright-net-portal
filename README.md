# Alternativa Internet - Portal Web

## Sobre o Projeto

Portal institucional da Alternativa Internet & Serviços - Provedor de internet banda larga de alta velocidade.

## Como Editar este Código

### Requisitos

Node.js & npm instalados - [instalar com nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Passos para Desenvolvimento Local

```sh
# Passo 1: Clone o repositório
git clone <SEU_URL_GIT>

# Passo 2: Navegue até o diretório do projeto
cd <NOME_DO_PROJETO>

# Passo 3: Instale as dependências necessárias
npm i

# Passo 4: Inicie o servidor de desenvolvimento
npm run dev
```

### Editar Arquivo Diretamente no GitHub

- Navegue até o(s) arquivo(s) desejado(s).
- Clique no botão "Edit" (ícone de lápis) no canto superior direito.
- Faça suas alterações e confirme as mudanças.

### Usar GitHub Codespaces

- Navegue até a página principal do seu repositório.
- Clique no botão "Code" (botão verde) próximo ao canto superior direito.
- Selecione a aba "Codespaces".
- Clique em "New codespace" para lançar um novo ambiente Codespace.
- Edite arquivos diretamente dentro do Codespace e confirme suas alterações quando terminar.
